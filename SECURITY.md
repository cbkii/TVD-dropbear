# TVD Dropbear security
Every enrolled key permits root administrative access. No password, no implied low-privilege separation. Fresh installs disabled and bound to loopback. Keep authenticated ADB, use dedicated Ed25519 keys, verify the host key independently, and do not expose SSH to the Internet. Key revocation affects subsequent authentication, not already authenticated sessions. Use ADB for lifecycle and rollback. Explicit acceptance of DE storage is required. No runtime updates or SELinux changes. Report sensitive findings privately to the repository owner; for upstream defects use the upstream project's disclosure channel. Testing artefacts are not stable releases. See [engineering reference](docs/TVD-ENGINEERING.md).
