# TVD Dropbear engineering rules
Target: cbkii/TVD-dropbear. Upstream VD171/VD-dropbear v1.11 at 5db14725c51be34e22c7fa9d3b7df491fa77a4c9.
Primary device Toshiba 50C350KP (internal 50C351P), HiSmartTV A4, Android 9/API 28, MStar MSD6886, root Magisk. Verify actual ABI, root and SELinux. No boot/firmware/partition work, no ADB changes, no changes to OTA or playback. Keep builds on host. Root SSH is powerful; private keys stay on host, dedicated public keys, strict host verification, no Internet exposure. Do not enable boot or LAN before temporary qualification and owner acceptance. Source tests/CI do not prove physical acceptance. Preserve upstream licences, exact dependency provenance and regression fixes. No automatic updater, no resident helper/watchdog. Stable release requires evidence bound to exact commit/artifact and human acceptance. See docs/TVD-ENGINEERING.md.
