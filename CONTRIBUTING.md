# Contributing to TVD Dropbear
Fork of VD171/VD-dropbear (Apache-2.0). Preserve original attribution and licences. See [AGENTS.md](AGENTS.md) and [engineering reference](docs/TVD-ENGINEERING.md). Keep changes reviewable, Android scripts POSIX/mksh-compatible, and test packaged artefacts. No unsafe release, mutation, credential exposure or automatic update path. Record exact source revisions, dependency hashes and device evidence. Do not treat upstream smartphone documentation as TVD runtime guidance.
